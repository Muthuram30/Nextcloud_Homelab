# Lessons Learned

## Project Reflection

This project was more than deploying a cloud storage application. It provided practical experience across networking, virtualization, cloud services, and system administration.

---

# Docker

Before this project I had limited experience with Docker.

During the deployment I learned:

- Images vs Containers
- Volumes
- Networks
- Environment variables
- Container lifecycle
- Log analysis

---

# Networking

Major topics learned:

- CGNAT
- DNS
- HTTPS
- Reverse proxies
- Cloudflare Tunnel
- Localhost vs public endpoints

---

# Storage

Important realization:

Storage planning should be completed **before** deployment.

Changing storage locations later increases complexity.

---

# Documentation

Maintaining documentation throughout the project significantly simplified troubleshooting and created a reusable reference for future deployments.

---

# Security

Key lessons:

- Never expose unnecessary ports.
- Use HTTPS for all external access.
- Protect secrets and API tokens.
- Separate administrator and standard user accounts.

---

# Project Management

The project reinforced the value of:

- Incremental changes
- Testing after each modification
- Version control
- Keeping notes of successful configurations
